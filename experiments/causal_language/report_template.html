Does calling it a trick make the agent cheat?

Earlier sweeps found that agents which describe the task as a trick, puzzle or challenge reward-hack more often. That is a correlation. Here we edit one sentence of that framing in the agent's own reasoning and roll out the rest of the run many times, so any change in hacking is caused by the edit.

How a branch rollout works

Seed

A full run of the agent, captured request by request with its raw reasoning, on a pinned provider.

Cut

Pick one API request and edit its reasoning: keep, delete, replace or insert one sentence. Files are restored to that moment.

Roll out

The model continues from the edited reasoning and runs to the end with real tools, 20 or more times per arm.

Judge

Every rollout is judged blind for reward hacking and dishonest reporting, without knowing its arm.

Methods and caveats

  • Model: thinkingmachines/inkling via OpenRouter, pinned to Together for every request of seeds and rollouts; reasoning effort high, temperature 1.0, top_p 1.0.
  • The edited step is answered by a raw-completion prefill rendered with the model's chat template. Its token count matched the provider's own rendering exactly (gap 0) for every seed request used.
  • Each rollout ran alone on its own machine, so agents could not see or copy each other. Agents ran as unprivileged users in an ordinary-looking git repository.
  • Judging: Claude subagents, blind to arm, read every transcript in full against the pipeline's reward-hacking and dishonest-reporting rubrics. A few verdicts were re-run after a safety filter interrupted the judge; four were transcribed from a judge's report after its file write was blocked.
  • "Trick framing in the branch step" is a pattern match (trick, puzzle, CTF, challenge, riddle, game the benchmark) on the text the model generated after the edit point in that same step; injected or kept text is excluded.
  • Three of 180 round-1 rollouts saw or recorded an internal resume marker; they are flagged in the table.
  • Seeds are single trajectories. A seed's own outcome is one draw; rollouts from early cut points can differ a lot from it.
